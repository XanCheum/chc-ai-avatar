# Project: CHC AI Avatar Prototype (student research project)

- Build a simple, mobile-first static website: plain HTML, CSS and JavaScript only.
- No frameworks, no build tools, no backend, no API keys, no paid services.
- Must run on GitHub Pages and work on iPhone Safari and Android Chrome.
- All story content comes ONLY from content/stories.json. Never invent historical facts.
- The avatar is a fictional character. Show a small label: "Prototype – fictional character based on CHC stories".
- Keep code short and well commented so non-programmers can edit content.
